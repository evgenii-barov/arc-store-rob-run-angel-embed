ARC STORE × ROB RUN — АНИМИРОВАННЫЙ БАННЕР ДЛЯ OBS

Файл: index.html
Форматы: 1920×180 и 1280×120 (один адаптивный макет)
Фон страницы: прозрачный
Звук: отсутствует
Цикл: бесшовный

КАК ДОБАВИТЬ В OBS

1. В OBS нажмите «+» в блоке «Источники».
2. Выберите «Браузер» / Browser Source.
3. Включите «Локальный файл» / Local file.
4. Выберите файл index.html из этой папки.
5. Установите один из размеров:
   • 1920 × 180 — для сцены 1920×1080;
   • 1280 × 120 — для сцены 1280×720.
6. FPS: 30 или 60.
7. Включите «Обновлять браузер при активации сцены».

Рекомендуемое размещение: по нижнему краю игровой сцены.

Баннер использует только локальные файлы. Интернет для его работы не нужен.
Не переименовывайте папку assets и не выносите index.html отдельно от styles.css.

КОМПАКТНЫЙ ВАРИАНТ — РЕКОМЕНДУЕТСЯ ДЛЯ ПОСТОЯННОГО ПОКАЗА

Файл: compact.html
Форматы: 720×90 для сцены 1920×1080 или 480×60 для сцены 1280×720.
Текст меняется каждые три секунды: статус партнёра → скидка и промокод → адрес магазина.
Подключается тем же способом через «Браузер» / Browser Source, но выбирается compact.html.
Рекомендуемое размещение: верхний правый угол с отступом от края; проверьте, что плашка не закрывает игровой HUD.
