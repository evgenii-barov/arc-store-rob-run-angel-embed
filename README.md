## Главные ссылки

- Партнёрская страница: `https://arc-store.ru/rob-run/partners/angel/?ref=angel`
- Прямая ссылка в каталог: `https://arc-store.ru/rob-run/?ref=angel`
- Промокод зрителей: `ANGEL`

Параметр `ref=angel` оставляйте во всех ссылках. После перехода на ARC Store партнёрская метка хранится в браузере до 30 дней. Приватный кабинет передаётся отдельно и никогда не должен попадать в сайт, описание стрима или этот репозиторий.

## Twitch

### Баннер на стриме

Основной вариант страницы ROB RUN:

- `banners/angel-obs-compact-720x90.webm` — рекомендуемая компактная плашка для эфира 1080p; текст меняется каждые три секунды.
- `banners/angel-obs-compact-480x60.webm` — компактная версия для эфира 720p.
- `banners/angel-obs-animated-1920x180.webm` — прозрачная анимированная плашка для OBS, эфир 1080p.
- `banners/angel-obs-animated-1280x120.webm` — прозрачная анимированная плашка для OBS, эфир 720p.
- `banners/angel-obs-1920x180.png` — прозрачная плашка для OBS, эфир 1080p.
- `banners/angel-obs-1280x120.png` — прозрачная плашка для OBS, эфир 720p.

WebM-файл добавьте как «Источник медиа» и включите повтор. Для постоянного показа используйте компактную версию в верхнем правом углу; широкую — как периодический рекламный выход. HTML-варианты для «Источника браузер» находятся в `obs-browser-source/`. Статичный PNG добавляется как «Источник изображения». Чёрно-зелёные исходники имеют суффикс `-green`; бордово-красные альтернативы — `-red`.

### Панель под стримом

Загрузите `banners/angel-twitch-panel-320x180.png` и назначьте ей ссылку на партнёрскую страницу. Готовый HTML-пример находится в `snippets/panel-link.html`.

### Баннер профиля

`banners/angel-twitch-profile-1200x480.png` — дополнительный баннер профиля. Он содержит короткую формулировку «Официальный партнёр ARC Store» без имени и ника; она относится к магазину, а не к разработчикам ROB RUN.

## Встраивание страницы

Вставьте в Custom HTML:

```html
<script src="https://evgenii-barov.github.io/arc-store-rob-run-angel-embed/embed.js" defer></script>
```

Скрипт создаёт изолированный адаптивный iframe и проверяет источник сообщений о высоте. Магазин и оформление заказа открываются на `arc-store.ru` в новой вкладке. Копия на GitHub Pages не устанавливает партнёрскую cookie: атрибуция начинается после перехода на ARC Store.

Если CMS удаляет скрипты, используйте `snippets/card.html`, обычную панель или прямую ссылку. Не встраивайте checkout или приватный кабинет в iframe.

## Файлы

- `index.html`, `landing.css`, `page.js` — публичная адаптивная страница.
- `embed.js`, `embed-example.html` — безопасное встраивание с авто-высотой.
- `banners/` — зелёный основной и красный дополнительный комплект Twitch.
- `obs-browser-source/` — широкая и компактная локальные HTML-анимации для OBS Browser Source.
- `animation-source/` — воспроизводимые Remotion-исходники прозрачных WebM-анимаций.
- `logo/` — полный логотип ARC Store с тележкой, текстовый wordmark и логотип ROB RUN.
- `snippets/` — готовые варианты размещения.

ARC Store — независимый сервис и не является официальным представителем разработчиков ROB RUN. Название и игровые изображения принадлежат их правообладателям. Для рекламного размещения используйте понятную пометку о партнёрской ссылке.
